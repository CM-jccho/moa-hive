실행 · 모바일 가이드

기본 실행 형태는 macOS 데스크톱 앱(로컬 실행)입니다. 설치 없이 폴더에서 바로 켭니다.

  1. Node.js 확인 — 터미널에서 node -v (v18 이상). 없으면 nodejs.org에서 설치.
  2. 한 번만 권한 주기 — chmod +x start.command
  3. 실행 — start.command 더블클릭 (처음엔 우클릭 → 열기) 또는 터미널에서 node server.js
  4. 브라우저 — http://127.0.0.1:3847 이 자동으로 열립니다.
  5. 독에 고정 — Safari: 파일 → 독에 추가 / Chrome: 주소창 오른쪽 설치 아이콘. 아이콘을 누르면 앱처럼 전체 화면으로 열립니다.
데이터는 이 Mac의 moa-hive/data/에만 저장됩니다. 창을 닫으면 서버도 꺼집니다.

배포용으로는 Electron으로 감싸 .dmg로 만들 수 있습니다. 서버 코드는 그대로 쓰고 창만 씌우는 방식입니다.

  1. 개발 의존성 설치
    npm i -D electron electron-builder
  2. main.js 만들기
    const { app, BrowserWindow } = require('electron');
const { spawn } = require('child_process');
const path = require('path');
let srv;
app.whenReady().then(() => {
  srv = spawn(process.execPath, [path.join(__dirname, 'server.js')], {
    env: { ...process.env, ELECTRON_RUN_AS_NODE: '1', PORT: '3847' },
  });
  const win = new BrowserWindow({ width: 1440, height: 900, titleBarStyle: 'hiddenInset' });
  setTimeout(() => win.loadURL('http://127.0.0.1:3847'), 700);
});
app.on('quit', () => srv && srv.kill());
  3. package.json에 build 설정
    "main": "main.js",
"build": {
  "appId": "com.moa.hive",
  "productName": "MOA Hive",
  "files": ["server.js", "config.js", "public/**", "market/**", "version.json", "CHANGELOG.md"],
  "mac": { "target": ["dmg"], "category": "public.app-category.productivity" }
}
  4. 빌드
    npx electron-builder --mac --arm64
# → dist/MOA Hive-0.2.0-arm64.dmg
  5. 배포 — 서명·공증 없이도 본인 Mac에서는 우클릭 → 열기로 실행됩니다. 지인에게 나눌 때는 Apple Developer ID 서명 + 공증(notarize)을 권장합니다.
Electron 샌드박스에서는 봇의 cwd를 사용자가 고른 폴더로 지정하세요. macOS Ventura 이상은 파일 접근 권한을 한 번 물어봅니다.

부가 기능입니다. Mac에서 켜 둔 MOA Hive를 아이폰·안드로이드 브라우저로 조작합니다. 기본은 127.0.0.1 전용이라, 아래 방법 중 하나를 골라야 휴대폰에서 열립니다.

상태 확인 중…

A. 같은 Wi-Fi (가장 간단)

  1. 설정 → 모바일 원격 접속 → 같은 Wi-Fi에서 접속 허용 체크 → 설정 저장
  2. 터미널에서 서버 재시작: node server.js (또는 start.command)
  3. 위 상태 상자의 Wi-Fi 주소(토큰 포함)를 아이폰 사파리에 입력
  4. 사파리 공유 → 홈 화면에 추가 → 앱처럼 실행
공용 Wi-Fi(카페·호텔)에서는 켜지 마세요. 같은 네트워크의 다른 기기가 접근할 수 있습니다. 토큰이 없으면 열리지 않습니다.

B. Tailscale (밖에서도, 추천)

  1. Mac과 아이폰에 Tailscale 설치 후 같은 계정으로 로그인
  2. Mac 터미널: tailscale serve --bg 3847
  3. 아이폰에서 표시된 https://<기기>.<tailnet>.ts.net 열기 — 127.0.0.1 그대로라 서버 설정 변경 불필요

C. Cloudflare Tunnel (무료, 링크 공유)

  1. Mac: brew install cloudflared
  2. 토큰 강제 모드로 서버 실행: MOA_REQUIRE_TOKEN=1 node server.js
  3. 다른 터미널: cloudflared tunnel --url http://127.0.0.1:3847
  4. 발급된 https://….trycloudflare.com 주소를 아이폰에서 열고 토큰 입력
터널 주소를 아는 사람은 접근할 수 있습니다. MOA_REQUIRE_TOKEN=1로 토큰을 반드시 켜고, 오래 쓸 거면 Cloudflare Access 정책을 거세요.
🔒

내 PC 안에서만 도는 AI 팀

MOA Hive는 대화·문서·API 키를 이 Mac 밖으로 보내지 않습니다.

100% 로컬 실행봇·대화·설정이 모두 ./data/에만 저장됩니다.
외부 서버 유출 없음API 키는 원문이 다시 표시되지 않고, 조회 API도 configured만 반환합니다.
모든 실행 전 승인셸·파일 작업은 Allow/Deny 카드 없이는 절대 실행되지 않습니다.

AI를 어디서부터 써야 할지 모르겠다면, 업종·역할만 고르세요. 맞는 봇 조합과 활용법을 컨설팅해 드립니다.
