Setup

설치 3단계

앱 설치본을 쓰거나, 저장소를 받아 스크립트로 바로 실행할 수 있습니다. 두 방법 모두 데이터는 내 PC의 data/ 폴더에만 남습니다.

  1. .dmg 내려받아 설치

    MOA-Hive-0.3.0-universal.dmg를 열고 MOA Hive를 Applications로 옮깁니다.

  2. 처음 한 번만 열어 주기

    서명 전 빌드는 Finder에서 앱을 우클릭 → 열기로 실행합니다. 이후에는 그냥 더블클릭.

  3. 앱 안에서 바로 사용

    앱이 로컬 서버(127.0.0.1:3847)를 띄우고 창을 엽니다. 창을 닫으면 서버도 종료됩니다. 데이터는 ~/Library/Application Support/MOA Hive/home/data/에 저장됩니다.

💡 스크립트로 실행하려면: 저장소를 받아 chmod +x start.command 후 더블클릭. Node.js v18 이상이 필요합니다.
  1. 설치 파일 실행

    MOA-Hive-Setup-0.3.0.exe를 실행합니다. SmartScreen 경고가 뜨면 추가 정보 → 실행.

  2. 설치 마법사 완료

    설치 위치를 고르고 완료하면 시작 메뉴와 바탕화면에 MOA Hive가 생깁니다. 앱이 로컬 서버를 함께 띄웁니다.

  3. 스크립트 실행(대안)

    Node.js v18 이상이 있으면 start.bat 더블클릭만으로 node server.js가 실행되고 브라우저가 열립니다.

🔒 서버는 127.0.0.1에만 바인딩됩니다. Windows 방화벽 알림이 뜨면 “취소”해도 앱은 정상 동작합니다.
  1. 저장소 받기 
    git clone https://github.com/CM-jccho/moa-hive.git
cd moa-hive
  2. 의존성 없이 실행 
    node server.js        # → http://127.0.0.1:3847

    npm install이 필요 없습니다. 포트를 바꾸려면 PORT=3900 node server.js.

  3. 데스크톱 앱으로 빌드(선택) 
    npm install
npm run dist:mac      # dist/MOA-Hive-0.3.0-universal.dmg
npm run dist:win      # dist/MOA-Hive-Setup-0.3.0.exe
🧪 테스트: node tests/reset_state.js && node server.js 후 python3 tests/api_test.py, python3 tests/ui_test.py, python3 tests/web_test.py.

🧭 팀 컨설팅

업종을 고르거나, 하고 싶은 일을 그대로 적어 주세요.

체험판은 실제 파일·셸을 실행하지 않습니다. 데스크톱 앱에서는 같은 흐름이 로컬 CLI/API로 이어지고, 실행 전 승인 카드가 뜹니다.

Mobile

휴대폰에서도 같은 팀

기본은 PC 안에서만 실행됩니다. 밖에서 쓰려면 아래 세 가지 중 하나를 고르세요. 어느 경우든 접속 토큰이 없으면 열리지 않습니다.

📶 같은 Wi-Fi 가장 간단

설정 → 모바일 원격 접속 → “같은 Wi-Fi에서 접속 허용”을 켜고 재시작하면, Wi-Fi 주소(토큰 포함)가 표시됩니다. 아이폰 사파리에서 열고 홈 화면에 추가.

🔐 Tailscale 밖에서도

Mac·아이폰에 Tailscale을 설치하고 같은 계정으로 로그인한 뒤, Mac 터미널에서 tailscale serve --bg 3847. 발급된 https://…ts.net 주소로 접속합니다.

Tailscale 받기

☁️ Cloudflare Tunnel 링크 공유

MOA_REQUIRE_TOKEN=1 node server.js로 토큰을 강제한 뒤 cloudflared tunnel --url http://127.0.0.1:3847. 발급된 주소를 휴대폰에서 열고 토큰을 입력합니다.

cloudflared 안내

⚠️ 터널 주소를 아는 사람은 접근할 수 있습니다. 공유 링크는 짧게 쓰고, 장기 사용 시 Cloudflare Access 정책을 거세요.

Privacy by design

왜 안전한가

편의를 위해 데이터를 밖으로 보내지 않습니다. 서버·저장·실행 권한이 모두 내 PC 안에서 닫힙니다.

🔒

루프백 전용 바인딩

서버는 127.0.0.1에만 열립니다. 원격은 직접 켤 때만, 그때도 토큰이 필수입니다.

💾

로컬에만 저장

대화·봇 설정·승인 이력은 ./data/의 JSON에만 남습니다. 클라우드 동기화가 없습니다.

🔑

API 키 마스킹

키는 저장 후 조회 API가 원문을 반환하지 않습니다. 화면·로그에도 원문이 나오지 않습니다.

✋

Allow / Deny 승인

셸·파일 작업은 제안 → 사용자 클릭 → 재검증 → 실행 순서를 지킵니다. 위험 명령은 차단됩니다.

📁

경로 샌드박스

봇의 작업 폴더는 허용 루트 안으로 제한합니다. ..·절대경로·심볼릭 링크 이탈을 막습니다.

🛡️

PROD 읽기 전용

운영 환경은 직접 수정할 수 없습니다. STG에서 검토하고 Release Manager로만 승격합니다.
