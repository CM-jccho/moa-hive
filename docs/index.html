명령줄이 익숙한 분만 보세요. 위 설치 파일 없이 소스에서 바로 실행할 수 있습니다.

  • start.command(Mac) / start.bat(Windows)을 더블클릭하면 실행됩니다. Node.js v18 이상이 필요합니다.
  • 소스: ZIP 내려받기 · GitHub 저장소
  • 실행: git clone https://github.com/CM-jccho/moa-hive.git → cd moa-hive → node server.js → http://127.0.0.1:3847
  • 앱 빌드: npm install → npm run dist:mac 또는 npm run dist:win
  • Apple Silicon 전용 arm64 · Intel 전용 x64 · start.command · start.bat

업종을 고르거나, 하고 싶은 일을 그대로 적어 주세요.

체험판은 실제 파일을 건드리지 않습니다. 앱에서는 같은 흐름이 실제 작업으로 이어지고, 실행 전에 항상 확인을 받습니다.

휴대폰

외출 중엔 휴대폰으로 이어서

기본은 내 컴퓨터 안에서만 열립니다. 밖에서도 쓰고 싶을 때만 아래 중 하나를 켜세요.

📶 집·사무실 와이파이 가장 간단

앱 설정에서 휴대폰 연결을 켜면 화면에 주소가 나옵니다. 그 주소를 휴대폰 브라우저에서 열고 홈 화면에 추가를 누르면 앱처럼 쓸 수 있습니다.

🔐 집 밖에서도 안전

Mac과 휴대폰에 Tailscale을 설치하고 같은 계정으로 로그인하세요. 앱 안의 휴대폰 연결 안내를 그대로 따라 하면 됩니다.

설정 명령 보기tailscale serve --bg 3847
Tailscale 받기

☁️ 링크로 잠깐 공유 고급

잠깐 링크로 보여주고 싶을 때만 쓰세요. 접속 토큰을 켜 두면 링크를 아는 사람도 토큰 없이는 들어올 수 없습니다.

설정 명령 보기MOA_REQUIRE_TOKEN=1 node server.js
cloudflared tunnel --url http://127.0.0.1:3847
cloudflared 안내

⚠️ 공유 링크는 필요한 동안만 짧게 쓰고, 쓰지 않을 때는 꺼 두세요.

안전한 설계

내 컴퓨터 안에서만, 안전하게

AI를 쓰면서도 자료가 밖으로 새지 않도록, 처음부터 그렇게 만들어졌습니다.

🔒

내 컴퓨터 밖으로 안 나감

앱은 내 컴퓨터 안에서만 열립니다. 같은 와이파이에서도 직접 켜기 전에는 접근할 수 없습니다.

💾

대화는 내 컴퓨터에만

대화·자료·설정은 이 컴퓨터 안에만 저장되고, 클라우드로 보내지 않습니다.

✋

중요한 실행은 먼저 확인

파일을 만들거나 명령을 실행하기 전에 항상 “해도 될까요?” 하고 물어봅니다.

🔑

비밀 키는 화면에 안 보임

AI 서비스 키를 넣어도 저장한 뒤에는 다시 보여주지 않습니다.

📁

정해진 폴더만 사용

봇이 일할 수 있는 폴더를 정하면 그 밖의 파일은 건드리지 않습니다.

🛡️

실수로 운영을 망치지 않게

관리자 모드에서만 버전을 바꿀 수 있고, 확인 전에는 운영에 반영되지 않습니다.
