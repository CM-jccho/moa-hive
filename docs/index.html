휴대폰

휴대폰에서도 그대로

웹 사무실은 휴대폰 브라우저에서도 열립니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다. 스토어도, 설치 파일도 필요 없습니다.

📱 홈 화면 가장 간단

사파리·크롬에서 주소를 열고 공유 → 홈 화면에 추가를 누르면 앱처럼 전체 화면으로 열립니다.

🔐 집 밖에서도 안전

데스크톱 앱을 쓰는 경우, Mac과 휴대폰에 Tailscale을 설치하고 같은 계정으로 로그인한 뒤 앱의 휴대폰 연결 안내를 따르세요.

설정 명령 보기tailscale serve --bg 3847
Tailscale 받기

☁️ 링크로 잠깐 공유 고급

잠깐 링크로 보여주고 싶을 때만 쓰세요. 접속 토큰을 켜 두면 링크를 아는 사람도 토큰 없이는 들어올 수 없습니다.

설정 명령 보기MOA_REQUIRE_TOKEN=1 node server.js

안전한 설계

설치 없이 시작하고, 자료는 내 쪽에만

웹 체험판은 이 브라우저 탭 안에서만 돌고 입력한 내용을 어디로도 보내지 않습니다. 데스크톱 앱은 모든 자료를 내 컴퓨터에만 저장합니다.

🌐

설치 파일 없이 웹에서

서명되지 않은 설치 파일이 없으니 “확인되지 않은 개발자” 경고도 없습니다. 주소를 열면 바로 시작합니다.

💾

체험 데이터는 탭 안에

체험 대화는 이 탭 안에만 있습니다. 데스크톱 앱은 내 컴퓨터의 ./data/ 에만 저장합니다.

✋

중요한 실행은 먼저 확인

파일을 만들거나 명령을 실행하기 전에 항상 “해도 될까요?” 하고 물어봅니다.

🔑

API 키 없이 시작

웹 체험은 키가 필요 없습니다. 앱에서 키를 넣어도 저장한 뒤에는 다시 보여주지 않습니다.

📁

정해진 폴더만 사용

봇이 일할 수 있는 폴더를 정하면 그 밖의 파일은 건드리지 않습니다.

🛡️

서버비 0원

정적 호스팅만 씁니다. 빌려야 할 서버도, 켜 둘 프로세스도 없습니다.

고급 · 개발자

Windows용 내려받기

설치 중 파란 경고가 나오면 추가 정보 → 실행을 한 번만 눌러 주세요.

  1. 설치 파일 열기

    MOA-Hive-0.3.4-universal.dmg

  2. Applications 폴더로 옮기기

  3. MOA Hive 실행

    처음 한 번 경고가 뜨면 완료 → 시스템 설정 > 개인정보 보호 및 보안 → 확인 없이 열기. 그다음부터는 더블클릭으로 열립니다.

  4. 하고 싶은 일 말하기

    “이번 주 할 일 정리해줘”처럼 입력하거나 🎤를 눌러 말합니다.

명령줄이 익숙한 분만 보세요. 위 설치 파일 없이 소스에서 바로 실행할 수 있습니다.

  • start.command(Mac) / start.bat(Windows)을 더블클릭하면 실행됩니다. Node.js v18 이상이 필요합니다.
  • 소스: ZIP 내려받기 · GitHub 저장소
  • 실행: git clone https://github.com/CM-jccho/moa-hive.git → cd moa-hive → node server.js → http://127.0.0.1:3847
  • 앱 빌드: npm install → npm run dist:mac 또는 npm run dist:win
  • Apple Silicon 전용 arm64 · Intel 전용 x64 · start.command · start.bat
